# YOUNIQS AI EDITOR 実演版（勉強会の担当者向け）の配布ページ

勉強会で、その場で動画を作って見せるためのアプリです。ここには配るファイルだけを置きます。

## 新しい版が出たら

アプリが自分で見つけて、画面の真ん中に「新しい版に更新しますか？」と出します。**「はい、更新する」を押すだけ**で入れ替わり、アプリが開き直します。ダウンロードし直す必要はありません。作った案件と設定は、そのまま残ります。

勉強会の本番の直前に出たときは「あとで」を押し、終わってから更新してください（更新の間はアプリが一度閉じます）。

## 初めて入れるとき

[最新版のページ](https://github.com/AI-E-Studio/youniqs-ai-editor-demo-releases/releases/latest)の「Assets」から、お使いのパソコンに合うファイルを選んでください。

| お使いのパソコン | 選ぶファイル |
|---|---|
| Windows 10/11（64ビット） | `YOUNIQS-AI-EDITOR-Demo-…-x64.exe` |
| Mac（M1 以降） | `YOUNIQS-AI-EDITOR-Demo-…-arm64.dmg` |
| Mac（Intel） | `YOUNIQS-AI-EDITOR-Demo-…-x64.dmg` |

- Windows：「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します（署名前の版のため、最初の1回だけ要ります）。
- Mac：「開けません」と出たら「完了」を押し、「システム設定」→「プライバシーとセキュリティ」の下の方の「このまま開く」を押します（最初の1回だけ要ります）。

## 使う前に必要なもの

- Claude の有料プラン（Pro・Max など）
- 初回は「はじめての準備」の画面で、光っているボタンを上から順に押してください。
- 勉強会の前日に、一度最後まで作ってください。そのパソコンでかかる時間を覚えて、当日は「あと約◯分」が出るようになります。
